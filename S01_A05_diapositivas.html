Qué tiene que lograr

Al terminar, su computador compila C

Esta cápsula no le enseña a programar. Le entrega la herramienta con la que va a programar durante los tres meses siguientes.

Lo que debe quedar
  • Un entorno instalado en su equipo que compila y ejecuta C.
  • Saber compilar y ejecutar desde ese entorno.
  • Una captura de pantalla con su nombre impreso por un programa que usted compiló.
Por qué en la semana 1

En la semana 3 usted escribe su primer programa real en C (cápsulas 3.1 y 3.2). Quien llegue allí sin compilador queda bloqueado en todo lo que sigue.

Instalar ahora le deja dos semanas de margen para resolver cualquier problema por los canales del curso.

La evidencia de esta cápsula no es un examen: es una captura de pantalla de su propia máquina funcionando.

Editor ≠ entorno de desarrollo

De texto a programa hacen falta cinco piezas

El Bloc de notas puede escribir un programa en C perfectamente válido. Lo que no puede es convertirlo en algo que la máquina ejecute.

1EditorEscribe y colorea el código
→
2CompiladorTraduce el .c a instrucciones de máquina
→
3EnlazadorUne su código con las bibliotecas y produce el ejecutable
→
4DepuradorDetiene el programa y muestra cada variable
→
5GestorRecuerda qué archivos forman el programa
Un IDE es esas cinco piezas en una sola ventana, con un botón que las coordina. Sin IDE habría que invocar cada pieza a mano — y en las rutas de macOS y Linux lo haremos al menos una vez, porque entender qué pasa por debajo vale la pena.

Ojo con la fila (e). PSeInt y Flowgorithm llegan en la cápsula 2.2, pero no compilan C: quien instale solo PSeInt no cumplió la 1.5.

Criterio del curso — gratuito, liviano, con compilador incluido y sin configuración previa — lo pone en el tipo (a): Dev-C++ de Embarcadero. No por ser el mejor IDE, sino el que menos cosas puede salir mal en la semana 1.

Ruta recomendada —

    Windows · ruta recomendada

    Dev-C++ de Embarcadero, en cuatro pasos

    Instalar
    • Descargue de sourceforge.net/projects/embarcadero-devcpp el archivo que dice TDM-GCC_9.2.
    • Si Windows avisa "Windows protegió su PC" → Más información → Ejecutar de todas formas. Es normal.
    • Tipo de instalación: deje Full. Es la que incluye el compilador.
    Comprobar — el paso que casi todos saltan

    Herramientas → Opciones del compilador. En la lista de arriba debe aparecer:

    TDM-GCC 9.2.0 64-bit Release

    Si esa lista está vacía, descargó el instalador No_Compiler. Desinstale y vuelva a empezar con el archivo correcto.

    Requisitos oficiales: Windows 7, 8.1 y 10. Embarcadero no lista Windows 11 porque la versión 6.3 es anterior a ese sistema. En la práctica funciona sin problemas conocidos; si su equipo se comporta de forma extraña, use VS Code + MinGW, que sí está mantenido al día.

    Windows · las tres cosas que fallan

    Banderas, extensión y la ventana que se cierra

    1 · Banderas

    Herramientas → Opciones del compilador → General. Marque "Añadir los siguientes comandos" y escriba:

    -std=c99 -Wall -Wextra

    -std=c99 fija la versión del lenguaje. -Wall -Wextra piden advertencias. Las advertencias son material de estudio, no ruido.

    2 · Extensión

    Dev-C++ propone .cpp por omisión. Este curso es de C.

    Al guardar, escriba entorno.c con la extensión a mano, y elija el tipo C source files.

    El compilador decide qué lenguaje aplicar según la extensión: guardarlo como .cpp produce errores de C++ confusos.

    3 · La ventana negra
    F9Compilar
    F10Ejecutar — se cierra sola
    F11Compilar y ejecutar — use esta

    No es un error: el programa terminó y la consola se cerró con él. F11 la mantiene abierta.

    macOS

    Tres de las cuatro respuestas "obvias" ya no existen

    La ruta que sí funciona

    macOS trae el compilador clang, pero sin instalar. En la Terminal:

    # instala el compilador clang (~1 GB)
xcode-select --install
clang --version

# compilar y ejecutar
clang -std=c99 -Wall -Wextra entorno.c -o entorno
./entorno

    Encima, VS Code + la extensión C/C++ de Microsoft. Igual en Intel y en Apple Silicon.

    Lo que NO debe intentar
    • Dev-C++ — no existe para macOS. Es una aplicación de Windows.
    • Code::Blocks — ya no publica binarios para Mac; el último es de la 12.11.
    • Visual Studio for Mac — Microsoft lo retiró el 31 de agosto de 2024.
    • Xcode completo — funciona, pero son +10 GB para un programa de consola.

    En macOS la orden gcc existe, pero es un alias de clang. No es un error: para este curso son equivalentes.

    Linux

    La ruta más corta de las tres

    Instalar y comprobar 
    # Ubuntu, Mint, Debian
sudo apt update
sudo apt install build-essential

# Fedora, Red Hat
sudo dnf group install "Development Tools"

# verificar, compilar y ejecutar
gcc --version
gcc -std=c99 -Wall -Wextra entorno.c -o entorno
./entorno
    El IDE es opcional

    Con lo de la izquierda ya cumplió el objetivo de la cápsula. Si además quiere un IDE:

    • Geany — apt install geany. Liviano. F8 compila, F5 ejecuta.
    • Code::Blocks — apt install codeblocks. El más parecido a Dev-C++.
    • VS Code — el mismo de las otras rutas.

    Dev-C++ con Wine: se puede, pero añade una capa de emulación que falla de formas difíciles de diagnosticar. En Linux ya tiene GCC nativo — el mismo compilador que Dev-C++ empaqueta.

    Dos casos particulares

    Eclipse CDT · y el plan B que siempre funciona

    Eclipse CDT · tipo (b)

    Solo tiene sentido si usted ya usa Eclipse para Java. Es de tipo (b): viene sin compilador.

    • Primero el compilador — MinGW, Command Line Tools o build-essential.
    • Paquete Eclipse IDE for C/C++ Developers, o Help → Install New Software → C/C++ Development Tools.
    • File → New → Project → C/C++ → C Project → Executable · Empty Project.
    • Ejecutar: Run As → Local C/C++ Application.

    CDT descubre los compiladores recorriendo el PATH. Si la lista de Toolchains sale vacía, verifique con gcc --version antes de culpar a Eclipse.

    OnlineGDB · plan B válido

    Si su equipo no permite instalar programas o ninguna ruta le funcionó: se acepta al 100 % en la actividad evaluativa.

    • onlinegdb.com/online_c_compiler
    • Verifique que el lenguaje diga C — por omisión suele estar en C++.
    • Guarde su código en su propio computador. Lo que queda solo en el navegador se pierde.

    Límites: no funciona sin internet y no trabaja con archivos del disco — que se necesitan en la semana 10.
