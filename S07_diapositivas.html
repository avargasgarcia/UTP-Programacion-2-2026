Tamaño máximo y cantidad usada

N es el tamaño del vector (10 casillas). n es cuántas se usan (lo dice el usuario, de 1 a N). Los ciclos van hasta n, no hasta N.

El patrón

for (i = 0; i < n; i++): i toma 0, 1, …, n − 1. En el scanf, cada casilla lleva su &, como cualquier variable: &v[i].

Antes de cargar, se valida que n esté entre 1 y N.

Vectores y funciones

Una función recibe el vector y cuántos elementos usar

int maximo(int v[], int n);
...

...
    printf("Maximo: %d\n", maximo(puntos, N));

int maximo(int v[], int n)
{
    int i, m;

    m = v[0];
    for (i = 1; i < n; i++) {
        if (v[i] > m) {
            m = v[i];
        }
    }
    return m;
}
Maximo: 90
Minimo: 58
Promedio: 75.00
Desde 70: 5
El parámetro

int v[], con corchetes vacíos, y aparte int n: la función no sabe cuántos elementos hay si no se le dice. En la llamada va solo el nombre.

Máximo, mínimo, conteo

El máximo empieza en v[0], no en 0: con todos negativos, 0 sería un máximo falso.

Una regla nueva

El vector no se copia: la función cambia el original

    int x = 5;
    int v[N] = {1, 2, 3, 4};
...
    duplicar_numero(x);
    duplicar_vector(v, N);
...
void duplicar_numero(int x)
{
    x = 2 * x;
    printf("dentro: x = %d\n", x);
}

void duplicar_vector(int v[], int n)
{
    int i;

    for (i = 0; i < n; i++) {
        v[i] = 2 * v[i];
    }
}

Como en la semana 6: x de main sigue en 5.

vector: el mismo

La función trabaja sobre las casillas de main: quedan en 2 4 6 8.

Por eso una función puede llenar, invertir u ordenar un vector sin return. El porqué (qué se pasa en realidad) se explica con el modelo de memoria en la semana 9.

Qué pasa

Con <=, la última vuelta lee v[5], que no existe. Nadie avisa: el programa lee lo que haya en esa memoria.

El resultado no está definido (un número cualquiera, otra variable cambiada, el programa terminado): por eso aquí no se muestra una salida.

La regla

Índices válidos de v[N]: de 0 a N − 1. Ciclo: i < n, nunca i <= n. Si dentro usa v[i + 1], el último i es n − 2.

El diagrama de la función

Empieza con su nombre y parámetros y termina en «Retornar pos». El ciclo avanza mientras queden elementos y no se haya encontrado.

En main, la llamada va con el símbolo de subrutina y después se decide si pos vale −1 (diagrama completo en la lectura, sección 3.1).

int buscar(int v[], int n, int x)
{
    int i, pos;

    pos = -1;
    i = 0;
    while (i < n && pos == -1) {
        if (v[i] == x) {
            pos = i;
        }
        i++;
    }
    return pos;
}

Una mejora de la búsqueda lineal

El centinela: una comparación menos por vuelta

    /* N + 1: una casilla extra para el centinela */
    int codigos[N + 1] = {305, 112, 870, 441, 112, 629, 958, 230};

int buscar_centinela(int v[], int n, int x)
{
    int i;

    v[n] = x;
    i = 0;
    while (v[i] != x) {
        i++;
    }
    if (i < n) {
        return i;
    }
    return -1;
}

La idea

Se pone el valor buscado en la casilla extra v[n]. Así el ciclo siempre lo encuentra y no necesita preguntar i < n en cada vuelta. Al final, si se detuvo en n, lo que encontró fue el centinela: no está.

Precondición

Solo funciona si el vector está ordenado: al ver v[medio] se sabe en qué mitad no puede estar x.

¿Cuál conviene?

Contar comparaciones: lineal frente a binaria

/* una comparacion por cada elemento que se examina */
int comparaciones_lineal(int v[], int n, int x)
{
    int i, cuenta = 0;

    for (i = 0; i < n; i++) {
        cuenta++;
        if (v[i] == x) {
            return cuenta;
        }
    }
    return cuenta;
}

Peor caso con 16 elementos

Lineal: 16 (todos, cuando está al final o no está). Binaria: 5, porque cada paso deja la mitad: 16, 8, 4, 2, 1.

Y con más datos

Con un vector ordenado de 1000 elementos, el peor caso medido es 1000 comparaciones para la lineal y 10 para la binaria.

Medido probando todos los valores del vector y uno que no está. La lineal sirve para cualquier vector; la binaria exige que esté ordenado. Esta comparación se formaliza en la semana 13.

    v[j] = aux;

En la semana 6 no funcionaba

intercambiar(int a, int b) recibía copias: cambiaba las copias y main no se enteraba.

Aquí sí funciona

La función recibe el vector (que no se copia) y dos posiciones. Intercambia las casillas de main.

Los dos algoritmos de hoy, burbuja y selección, ordenan llamando a esta función una y otra vez.

Ordenar de menor a mayor se llama orden ascendente; de mayor a menor, descendente.

void burbuja(int v[], int n)
{
    int pasada, j, hubo_cambio;

    hubo_cambio = 1;
    for (pasada = 1; pasada < n && hubo_cambio; pasada++) {
        hubo_cambio = 0;
        for (j = 0; j < n - pasada; j++) {
            if (v[j] > v[j + 1]) {
                intercambiar(v, j, j + 1);
                hubo_cambio = 1;
            }
        }
    }
}

El for de adentro va hasta n − pasada: lo que ya llegó al final no se vuelve a revisar, y v[j + 1] nunca se sale.

La bandera

Si una pasada no cambia nada, el vector ya está ordenado

hubo_cambio

Antes de cada pasada vale 0; si hay un intercambio, pasa a 1. El for de afuera sigue solo mientras pasada < n y la pasada anterior cambió algo.

La pasada que no cambia nada también se hizo: es la que demuestra que ya está ordenado.

Sin la bandera, la burbuja hace siempre n − 1 pasadas.
