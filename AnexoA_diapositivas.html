Qué cubre este anexo

Agrupar en una sola variable los datos de una misma cosa

  • Declarar un registro con struct y typedef y usar sus campos con el punto.
  • Recorrer, buscar y ordenar un arreglo de registros.
  • Cargar y guardar registros en un CSV y en un archivo binario.

El concepto

Un registro: una variable, varios campos, una sola entidad

En la semana 11 un producto quedaba repartido en arreglos paralelos, unidos solo por la posición i:

cod[2]·nom[2]·precio[2]·exist[2]

Con un registro, el producto es una sola variable con cuatro campos:

cat[2]=.codigo 103.nombre "Cafe".precio 12000.0.existencias 3

Ventajas

Por qué vale la pena agrupar

Lo que se gana
  • Los datos viajan juntos: el precio de un producto no puede quedar al lado del nombre de otro.
  • El código se lee como el problema: cat[i].precio dice qué es.
  • Se copia con una asignación: b = a; copia todos los campos, cadenas incluidas.
  • Ordenar mueve el registro completo, en tres líneas.
  • Se guarda en binario con un solo fwrite y se recupera con un fread.
  • Un campo nuevo es una línea más en la declaración.
Dos cosas que no se pueden

Comparar registros con ==. Se compara campo por campo (strcmp para las cadenas).

Asignar con = a un campo de cadena. Se usa strcpy, como con cualquier cadena.

Las dos no compilan; el mensaje real de gcc está en la diapositiva 7.

Cómo se usa en C

Primero el tipo (la forma), después las variables

Con typedef · la forma del anexo 
typedef struct {
    int codigo;
    char nombre[20];
    double precio;
    int existencias;
} Producto;

Después, Producto se usa como int: Producto p; o Producto cat[5];. La declaración va fuera de main y no crea ninguna variable.

Sin typedef · sin_typedef.c 
struct Punto {
    int x;
    int y;
};
...
    struct Punto a = {3, 4};
    struct Punto b;
a = (3, 4)
b = (4, 8)

El tipo se llama struct Punto cada vez. Las dos formas son correctas.

Teclado y registros anidados

Cada campo se lee como su tipo; un campo puede ser otro registro

printf("Codigo: ");
scanf("%d", &e.codigo);
printf("Nombre (una palabra): ");
scanf("%29s", e.nombre);
printf("Nota: ");
scanf("%lf", &e.nota);

Los campos numéricos llevan &; el de cadena no, como en la semana 7.

Ordenar por un campo

Burbuja con bandera: el intercambio cambia, el algoritmo no

if (nota[j] < nota[j + 1]) {
    tnota = nota[j];
    nota[j] = nota[j + 1];
    nota[j + 1] = tnota;
    tc = cod[j];
    cod[j] = cod[j + 1];
    cod[j + 1] = tc;
    strcpy(tn, nom[j]);
    strcpy(nom[j], nom[j + 1]);
    strcpy(nom[j + 1], tn);
    cambio = 1;
}

Nueve líneas y tres auxiliares de tres tipos. Si se olvida un arreglo, las notas quedan pegadas al estudiante equivocado, sin aviso.

if (v[j].nota < v[j + 1].nota) {
    t = v[j];
    v[j] = v[j + 1];
    v[j + 1] = t;
    cambio = 1;
}

Tres líneas y un solo auxiliar Estudiante t. Un campo nuevo no cambia nada aquí.

Persistencia completa

Cargar al iniciar, operar en memoria, guardar al salir

int cargar(Producto v[], int max)
{
    FILE *f = fopen(ARCHIVO, "rb");
    int n = 0;

    if (f == NULL) {
        return -1;
    }
    while (n < max && fread(&v[n], sizeof(Producto), 1, f) == 1) {
        n++;
    }
    fclose(f);
    return n;
}

Guardar es un solo fwrite(v, sizeof(Producto), n, f) con "wb". Agregar al final sin borrar es "ab" (agregar_bin.c, lectura § 6.3).

Criterio

¿Texto o binario?

Texto (CSV)Binario
Se lee y se corrige con el Bloc de notas o una hoja de cálculosíno
Código para guardar y cargarfprintf, y fgets + sscanf, campo por campoun fwrite y un fread
Líneas mal formadashay que detectarlasno existen como tal, pero un archivo de otro programa se lee mal sin aviso
En otro computador o con otro compiladorse lee igualsolo es seguro con la misma declaración y el mismo compilador

Criterio práctico: texto si una persona necesita ver o editar los datos, u otro programa los va a leer; binario si solo los usa el mismo programa para recordar su estado entre ejecuciones.

typedef struct {
    int codigo;
    double precio;

int main(void)
{
    Item v[2] = {{1, 9.5}, {2, 7.0}};
    Item x;
    FILE *f;
    int n = 0;

    f = fopen("items.bin", "wb");
    fwrite(v, sizeof(Item), 2, f);
    fclose(f);
    f = fopen("items.bin", "wb");
    fwrite(v, sizeof(Item), 1, f);
    fclose(f);
    f = fopen("items.bin", "ab");
