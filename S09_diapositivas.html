Dos detalles

La suma de cada fila vuelve a 0 antes del ciclo de las columnas. La diagonal principal (m[0][0], m[1][1], …) necesita un solo ciclo: fila y columna son el mismo índice.

El error de siempre, en dos dimensiones

Salirse de la matriz: C tampoco lo detecta

#define FILAS 2
#define COLS 3
...

        for (j = 0; j <= COLS; j++) {
            suma = suma + m[i][j];

(gcc no muestra nada: cero errores y cero advertencias)
Qué pasa

Con <=, el ciclo de adentro llega a m[i][3], una columna que no existe. Compila sin avisar y el resultado no está definido: por eso no se muestra una salida.

La regla, dos veces

Filas de 0 a f − 1; columnas de 0 a c − 1. Cada ciclo con < y con su límite: el de las filas con f, el de las columnas con c.

void sumar(int a[][MAX], int b[][MAX], int s[][MAX], int f, int c)
{
    int i, j;

    for (i = 0; i < f; i++) {
        for (j = 0; j < c; j++) {
            s[i][j] = a[i][j] + b[i][j];
        }
    }
}

Transpuesta

La fila i pasa a ser la columna i

void transponer(int a[][MAX], int t[][MAX], int f, int c)
{
    int i, j;

    for (i = 0; i < f; i++) {
        for (j = 0; j < c; j++) {
            t[j][i] = a[i][j];
        }
    }
}

Cada casilla P[i][j] combina la fila i de A con la columna j de B: multiplica sus elementos uno a uno y los suma.

Cuándo existe

A (f1 × c1) por B (f2 × c2) solo existe si c1 == f2: cada fila de A debe tener tantos elementos como cada columna de B. El resultado es de f1 × c2.

No es casilla por casilla

A diferencia de la suma, el producto no multiplica las casillas en la misma posición. Y en general A × B no es igual a B × A.

int compatibles(int c1, int f2)
{
    return c1 == f2;
}

Cuánto trabajo

Contar multiplicaciones: n × n × n

Por qué n³

Para dos matrices de n × n: hay n × n casillas y cada una necesita n multiplicaciones. El contador del programa da exactamente n × n × n.

Qué significa

Al duplicar n, las multiplicaciones se multiplican por 8: de 8 con n = 2 a 64 con n = 4. Cómo crece el trabajo de un algoritmo se estudia más adelante en el curso.

Quitar el salto de línea

fgets guarda el '\n': se cambia por '\0' con strlen

/* si el ultimo caracter es el salto de linea, lo cambia por '\0' */
void quitar_salto(char s[])
{
    int largo;

    largo = (int) strlen(s);
    if (largo > 0 && s[largo - 1] == '\n') {
        s[largo - 1] = '\0';
    }
}
