La pila explica la semana 6

Los parámetros de una función son copias que viven en la pila mientras la función se ejecuta. Al volver, esa parte de la pila se descarta: por eso lo que la función hizo con sus copias se pierde.

Esquema simplificado, para razonar. El orden real de las zonas y sus direcciones dependen del sistema operativo y del compilador.

Direcciones

Cada variable vive en una dirección; & la entrega

int main(void)
{
    int edad = 19;
    double nota = 4.5;
    char letra = 'A';

    printf("edad  vale %d   y vive en %p\n", edad, (void *) &edad);
    printf("nota  vale %.1f  y vive en %p\n", nota, (void *) &nota);
    printf("letra vale %c    y vive en %p\n", letra, (void *) &letra);
    return 0;
}

Es el mismo & de scanf("%d", &x): scanf necesita saber dónde guardar.

Los dos papeles del *

En la declaración, int *p: «p es un apuntador a int». En una expresión, *p: «la variable a la que apunta p».

El error más grave de la semana

*p cuando p no apunta a ninguna variable

1 · p vale NULL 
int *p = NULL;
printf("Antes de usar *p\n");
*p = 5;
...

Compila sin avisos. Al ejecutar:

Antes de usar *p

Medido en Linux: termina por la señal SIGSEGV (violación de segmento) en *p = 5; la segunda línea nunca aparece.

2 · p sin inicializar 
int *p;

*p = 5;

p apunta a cualquier parte. gcc advierte:

'p' is used uninitialized [-Wuninitialized]

3 · un valor donde va una dirección 
int dato = 8;
int *r;
r = dato;
*r = *r + 1;

Falta el &. gcc advierte:

assignment to 'int *' from 'int' makes pointer from integer without a cast [-Wint-conversion]

La regla: todo apuntador nace en NULL o con una dirección (&x); si puede valer NULL, se pregunta if (p != NULL) antes de usar *p. Las versiones corregidas están en la lectura (G2).

La respuesta pendiente

Al llamar f(v, n) viaja la dirección de v[0], no las casillas. En un parámetro, int v[] es lo mismo que int *v.

Dónde queda cada casilla

v[i] está i casillas después de v[0]: con int de 4 bytes, 4 × i bytes (medido a la izquierda). En m[3][COLS], m[i][j] está a i × COLS + j casillas de m[0][0]: por eso el parámetro exige COLS.

sizeof, nuevo en el curso

sizeof(int) es el número de bytes de un int. Con él, el programa no depende de cuánto ocupa un tipo en cada computador.

Matrices dinámicas

La matriz dinámica es un vector de filas

int **crear_matriz(int f, int c)
{
    int i;
    int **m;

    if (f < 1 || c < 1) {
        return NULL;
    }
    m = malloc(f * sizeof(int *));
    if (m == NULL) {
        return NULL;
    }
    for (i = 0; i < f; i++) {
        m[i] = malloc(c * sizeof(int));
        if (m[i] == NULL) {
            liberar_matriz(m, i);
            return NULL;
        }
    }
    return m;
}

m[i][j]

m[i] es el apuntador a la fila i; m[i][j], su casilla j. Las filas son bloques aparte: no tienen que estar seguidas.

Liberar

Se libera en orden inverso: primero las filas, al final m

void liberar_matriz(int **m, int f)
{
    int i;

    for (i = 0; i < f; i++) {
        free(m[i]);
    }
    free(m);
}
